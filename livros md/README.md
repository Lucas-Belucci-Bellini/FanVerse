# Livros MD

Este diretório foi reservado para armazenar projetos em Markdown referentes aos livros, arcos e fichas de organização da FanFic.

## Objetivo
- centralizar os arquivos `.md` de cada obra;
- organizar arcos, capítulos, personagens e rascunhos;
- permitir a expansão futura para até 50 registros de livros/coleções em uma estrutura simples.

## Estrutura sugerida
- `livros-md/arquivos/`: armazenamento de capítulos e resumos;
- `livros-md/colecoes/`: agrupamentos por história, arco ou coleção;
- `livros-md/README.md`: índice e orientações do material.

> Este diretório foi criado como espaço inicial para futura catalogação e organização do conteúdo por usuário.
